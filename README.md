# MedRemind: Accessible Medication Manager
A minimalistic Android application designed specifically for elderly users and patients with Alzheimer's to manage and track daily medications.

## 🚀 Features
- **CRUD Operations:** Easily Add, Edit, and Delete medication logs.
- **Smart Notifications:** Automated reminders to ensure zero missed doses.
- **Accessibility First:** Clean, high-contrast minimalistic UI with a scrollable CardView for easy navigation.
- **Data Portability:** Export medication history to CSV format for sharing with healthcare providers.

## 🛠 Tech Stack
- **Language:** Java / Kotlin
- **UI:** Android XML, Material Design (CardView, RecyclerView)
- **Local Storage:** SQLite / Room Database (for medication logs)
- **Background Tasks:** WorkManager / AlarmManager (for notifications)Medication Reminder Application
